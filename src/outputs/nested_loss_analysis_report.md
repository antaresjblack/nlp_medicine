# 训练投影的信息损失分析（dev）

方法：用与训练阶段完全相同的“最长非重叠实体投影”拆分金标，统计被丢弃的内层实体；再与最终单层小模型的预测做严格实体级比对（start+end+type 全同）；最后计算若剩余未恢复实体全部预测正确（且不新增误报）时实体级 F1 的理论上限。

## 第一步：投影丢弃了什么

金标实体共 20300 个：投影保留 19077 个（94.0%），丢弃 1223 个（6.0%）。

被丢弃实体的类型分布：

| 类型 | 数量 |
|---|---:|
| bod | 1025 |
| dep | 2 |
| dis | 47 |
| dru | 7 |
| equ | 3 |
| ite | 109 |
| mic | 4 |
| pro | 25 |
| sym | 1 |

## 第二步：单层模型隐式恢复了多少

被丢弃的 1223 个内层实体中，单层模型已严格命中 1123 个（91.8%），未恢复 100 个。

| 类型 | 被丢弃 | 已恢复 | 未恢复 |
|---|---:|---:|---:|
| bod | 1025 | 956 | 69 |
| dep | 2 | 2 | 0 |
| dis | 47 | 43 | 4 |
| dru | 7 | 6 | 1 |
| equ | 3 | 3 | 0 |
| ite | 109 | 87 | 22 |
| mic | 4 | 3 | 1 |
| pro | 25 | 22 | 3 |
| sym | 1 | 1 | 0 |

## 第三步：词典通道与残余上限

已恢复实体中 789 个（70.3%）的（文本, 类型）对存在于训练词典——即词典跨度特征提供了内层信息通道；未恢复实体中仅 8 个在词典中（其余为词典未覆盖的 OOV 内层）。

| | TP | P | R | F1 |
|---|---:|---:|---:|---:|
| 当前单层模型 | 9742 | 0.3896 | 0.4799 | 0.4301 |
| 假设未恢复的 100 个全部预测正确 | 9842 | 0.3896 | 0.4848 | 0.4320 |

理论增益上限：**+0.0020** 个实体级 F1 点。

## 结论

训练投影只丢弃 6.0% 的金标实体（且 84% 为短内层身体部位），其中 91.8% 已被单层模型通过词典跨度特征隐式恢复；即使把剩余全部预测正确，实体级 F1 增益上限也不到 0.2 个点。在词典特征充足的条件下，单层 BIO 结构的嵌套信息损失在实践中可忽略。
