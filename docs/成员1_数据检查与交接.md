## 原始字段与交接约定

每条数据包含 `text` 和 `entities`，每个实体包含 `start_idx`、`end_idx`、`type`、`entity`。检查使用 Unicode 字符索引，起点从 0 开始，原始终点为闭区间；Python 切片应使用 `text[start_idx:end_idx + 1]`。JavaScript 需用 `Array.from(text)`，避免将 UTF-16 代码单元误当成字符。
